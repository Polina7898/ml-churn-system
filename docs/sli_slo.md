# SLI и SLO системы предсказания оттока

Индикаторы и целевые уровни описаны для всех трёх уровней мониторинга ML-системы: технического, модельного и бизнесового.

## 1. Технический уровень

| Компонент | SLI | SLO |
|---|---|---|
| Churn API | Доступность (доля успешных запросов за период) | ≥ 99.5% за 30 дней |
| Churn API | Latency p95 эндпоинта `/predict` | < 200 мс |
| Churn API | Доля ответов 5xx | < 1% запросов за 24 часа |
| Churn API | CPU utilization | < 70% в среднем за 5 минут |
| Churn API | Memory usage | < 80% выделенной памяти |
| MLflow | HTTP 200 на главной странице | ≥ 99% за 30 дней |
| Prefect | HTTP 200 на `/api/health` | ≥ 99% за 30 дней |
| Prometheus | Успешный сбор метрик с Churn API | ≥ 99% scrape-интервалов |

## 2. Модельный уровень

| Метрика | SLI | SLO |
|---|---|---|
| Качество классификации | ROC-AUC на офлайн-выборке | ≥ 0.82 |
| Качество классификации | F1-score | ≥ 0.70 |
| Качество классификации | Precision@TopDecile | ≥ 0.65 |
| Дрейф данных | PSI по ключевым признакам | < 0.1 |
| Качество данных | Доля пропусков в признаках | < 5% |
| Свежесть модели | Время с последнего переобучения | < 7 дней |

## 3. Бизнес-уровень

| Метрика | SLI | SLO |
|---|---|---|
| Удержание клиентов | Квартальный Churn Rate | ≤ 22% (целевое снижение с 26%) |
| Эффективность кампаний | Конверсия retention-офферов | ≥ 15% |
| Возвратность | Доля клиентов, оставшихся после контакта | ≥ 60% |
| CTR | Кликабельность персональных предложений | ≥ 8% |
| Экономика | ROI кампании удержания | ≥ 150% |

## Действия при нарушении SLO

| Нарушение | Реакция |
|---|---|
| Latency p95 > 200 мс | Алерт DevOps, автоскейл инстансов |
| Error rate > 1% | Откат на предыдущий релиз через CI/CD |
| ROC-AUC < 0.82 | Триггер Prefect-пайплайна переобучения |
| PSI > 0.1 | Запуск анализа данных, переобучение модели |
| Churn Rate растёт | Ретро по моделям и сегментам, A/B-тесты |
